# Decisions

## Core Framing
- **Framed as "observer-conditioned latent objects"** — NOT "crypto in vector space." The emphasis is on appearance, observer dependence, designed legibility, decoy views, and recoverability through clue or semantics.
- **Primary term: "Latent Anamorph"** (alternate: "Subspace Anamorph"). Chosen because it connects to the art-historical concept of anamorphosis while signaling the high-dimensional setting.

## Strategy
- **Art-first, tool-second.** Build the aesthetic/puzzle demo first (direct projection), then add semantic keying, then adapt into an embedding exploration tool. This gives a demoable artifact fast and a path to practical utility.
- **Three application tracks from one core object**: (1) puzzle/art, (2) semantic data-viewer / embedding microscope, (3) latent provenance signatures. The mathematical object should support all three.
- **The unique angle is the combination** of observer-conditioned reveal + decoy structure + relational decoding + polysemantic objecthood. Not any single one of these alone.

## Scope
- **What to claim**: new design framework, new interactive metaphor, new class of polysemantic geometric puzzles, possible tool for concept-guided vector space exploration.
- **What NOT to claim**: new cryptography, strong concealment guarantees, unique mathematical hardness without proof, universal interpretability of dense spaces.
- **Posture**: novel object class + interface paradigm + artistic method, with optional research/tooling extensions.

## Technical Defaults
- MVP ambient dimension: $d = 256$, $N = 2000$ points
- Three construction versions planned: direct projection (simplest), semantic-keyed (most novel for research), relational (deepest/hardest)
- Build Phase 1 (direct projection puzzle) first before attempting Phases 2-3

## Venue
- arXiv preprint initially, then CHI, SIGGRAPH, or NeurIPS Creative AI track
- Target length: 6000-8000 words
- No deadlines — move at our pace
